# Invoker

Skills, hooks, checkers, slash commands, and always-on instructions apply to Codex, Claude, and Cursor. Each harness keeps its own file and block shape. The behavior is the same on all three. A change only one of them can load is unfinished. An extra harness the installer already targets, such as OMP, keeps that target.

The planning, landing, and safety rules in `CLAUDE.md` and `.cursor/rules/` apply here too.
