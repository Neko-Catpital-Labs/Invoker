## Finding 2: SIGKILL escalation was dead code

Comment: https://github.com/Neko-Catpital-Labs/Invoker/pull/7053#discussion_r3696747763

Quoted finding:

> Fix: the `SIGKILL` escalation is dead code.
>
> `killTimer` is cleared as a side effect of `finish()`, and `finish()` runs synchronously right after `killTimer` is created inside the timeout handler. This cancels the escalation timer before it can fire. Even without that, the timer's own callback guards on `if (!settled)`, and `settled` is already `true` by the time it would run, since `finish()` sets it during the same synchronous timeout handler.
